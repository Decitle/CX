The editor places tiles for you—no manual tile-coordinate counting. Texture images are loaded once, and cells store only a texture ID plus a small zoom value (not image copies).
Texture zoom: 1× is normal. Below 1× repeats the pixel texture more tightly; above 1× zooms into the center of the texture. Use the Scale tool to apply the current zoom to existing tiles.
Projection: Orthogonal uses square top-down cells. Oblique / isometric maps the same logical tile grid onto 2:1 diamonds; entrances and collision coordinates remain the same. Overlay mode adds transparent art without replacing the ground underneath.
Collision tool: blue cells are solid; amber cells are explicitly non-solid. Unmarked cells inherit the texture default from assets/collision.json (or the legacy filename rule when that file is absent). Visual overlays never add collision.
